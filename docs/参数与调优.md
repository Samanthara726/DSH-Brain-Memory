# 参数与调优

> 所有旋钮都在环境变量和一次 `/write` 的参数里。**先看 [调整顺序](#调整顺序)，别一上来就改数字。**

## 一、记忆服务（`memory_service.py`）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `MEM_DB` | `state/memory/memory.db` | 库路径（相对仓库根） |
| `MEM_HOST` | `127.0.0.1` | **别改成 0.0.0.0**，没有鉴权 |
| `MEM_PORT` | `8790` | |
| `MEM_LOG` | `state/memory/memory-service.log` | |
| `MEM_INJECT_CAP` | `1200` | 注入块字数上限（200~2000） |
| `MEM_K` | `3` | 每次注入几段 |
| `MEM_MIN_SIM` | `0.30` | 长查询的字面相似度门槛 |
| `MEM_MIN_SIM_SHORT` | `0.20` | 短查询（≤8 字）的门槛 |
| `MEM_MIN_SCORE` | `0.22` | 综合分下限 |
| `MEM_MIN_IMPORTANCE` | `0.10` | 低于它的记忆不参与召回 |
| `MEM_FREEZE_BELOW` | `0.5` | 冻结线；`0` = 关掉冻结 |
| `MEM_EMBED_ENABLED` | `1` | `0` = 只用字面路 |
| `MEM_EMBED_URL` | `http://127.0.0.1:8794` | 向量服务 |
| `MEM_EMBED_TIMEOUT` | `2.5` | 秒 |
| `MEM_COS_MIN` | `0.36` | 余弦门槛 |
| `MEM_COS_FALLBACK` | `0.38` | 字面全空时「放一条语义兜底」的门槛 |
| `MEM_LEDGER_REMIND_HOURS` | `12` | 同一个约定两次提醒的冷却 |
| `MEM_RELATION_WORDS` | 见下 | 性格权重用的关系词，逗号分隔 |
| `MEM_SELF_NAMES` | 空 | 「她自己」在写入文本里的行前缀名字，逗号分隔 |

代码里写死的：

| 常量 | 值 | 说明 |
| --- | --- | --- |
| `PIN_IMPORTANCE` | `0.7` | 保护线：≥ 它永不衰减 |
| `DECAY_FLOOR` | `0.05` | 遗忘地板 |
| `TEXT_MAX` | `4000` | 单条记忆上限（超出截断） |
| `RRF_K` | `60` | 两路合并的平滑常数（一般不用动） |
| `FSRS_*` | 默认参数 | FSRS-5 公开默认值，不做训练 |

## 二、向量服务（`embed_service.py`）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `EMBED_HOST` / `EMBED_PORT` | `127.0.0.1` / `8794` | |
| `EMBED_MODEL_DIR` | `state/models/bge-base-zh-v1.5` | 换模型后必须 `/reindex` |
| `EMBED_THREADS` | `4` | CPU 线程数，别拉满（会跟别的服务抢） |
| `EMBED_MAX_TEXTS` | `64` | 一次最多编几条 |
| `EMBED_MAX_TOKENS` | `256` | 单条截断长度 |
| `EMBED_QUERY_PREFIX` | `为这个句子生成表示以用于检索相关文章：` | bge 的检索指令前缀，换模型要跟着改 |

**换模型的两个后果**：维度变了 → 旧向量全部作废；语义空间变了 → 旧向量不可比。
代码会自动发现「模型名不一致」并清掉旧向量，但你得自己跑 `/reindex` 补齐。

## 四、写入时能覆盖的三个数

```json
POST /write {
  "text": "…",
  "importance": 0.9,      // 值不值得记住（0~1，>=0.7 永不衰减）
  "personality": 0.8,     // 跟她自己/你们关系有多近（越高衰减越慢、召回越靠前）
  "emotion": 0.6,         // 情绪浓度
  "pin": true             // 直接钉住，永不衰减
}
```

不传就按文本自动估。**`pin` 要克制**：钉住的记忆永远在，钉多了库就不再「变薄」了。

## 调整顺序

按这个顺序排查，不要跳步：

**1. 先确认注入真的进了 prompt。**
把 `/context` 返回的 `block` 打印出来看一眼。这一步没通，后面调什么都是白调。

**2. 翻不到想要的 → 放松门槛。**
- 先降 `MEM_MIN_SCORE`（0.22 → 0.18）
- 再降 `MEM_MIN_SIM`（0.30 → 0.26）
- 短查询单独的 `MEM_MIN_SIM_SHORT` 也可以降

**3. 注入里全是无关的 → 收紧门槛 + 减少段数。**
- `MEM_K` 3 → 2
- `MEM_MIN_SIM` 0.30 → 0.36
- `MEM_INJECT_CAP` 1200 → 800

**4. 最后才动遗忘。**
- 「怎么什么都记得」→ 把 `PIN_IMPORTANCE` 之外的东西降下来：检查是不是 `pin` 用太多；
- 「怎么什么都想不起来」→ 降 `MEM_FREEZE_BELOW`（0.5 → 0.35），或提高写入时的 `importance`。

> 只改 `MEM_FREEZE_BELOW` 不会让记忆回来——它只是决定「还参不参与自动注入」。真正的复活是 `R` 回升（被手动翻到一次）。

## 五、一组按场景的推荐值

| 场景 | 建议 |
| --- | --- |
| 单人群聊 bot，消息不多 | 默认值就行 |
| 多群共用一本库 | `MEM_K=2`，`MEM_INJECT_CAP=800`，靠 `source` 自己筛 |
| 想让角色「记性特别好」 | `PIN_IMPORTANCE=0.75`，`MEM_FREEZE_BELOW=0.35` |
| 想让它「自然健忘」 | `MEM_FREEZE_BELOW=0.6`，写入时别给高 importance |
| 机器很弱（老 CPU） | 不上 embed 服务（`MEM_EMBED_ENABLED=0`），纯 2-gram 完全可用 |
